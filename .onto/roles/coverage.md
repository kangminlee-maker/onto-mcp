# coverage

## Perspective

이 lens는 대상 시스템을 **도메인 포괄 범위**의 관점에서 본다. 대상 도메인의 개념 공간을 시스템이 충분히 커버하는지, 누락된 하위 영역이 있는지, 참조 표준/프레임워크 대비 빈 영역이 있는지를 검증한다. 다른 lens들이 "존재하는 것의 정확성"을 검증하는 반면, 이 lens는 "존재해야 하는데 없는 것"을 체계적으로 식별한다. 누락은 하위 영역 단위만이 아니라 차원 단위로도 나타난다 — 존재하는 요소가 운영에 필요한 차원(시간성, lifecycle, 감사 추적, 단일 권위 지정)을 결여할 수 있다.

이 관점은 도메인 개념 공간의 포괄 범위에만 초점을 둔다. 기존 요소 간의 내부 연결 완결성이나 불필요한 요소 식별은 별도 관점의 범위이다.

### Observation focus

누락된 하위 영역, 참조 표준 대비 빈 개념 범주, 상위 개념만 있고 하위 세분화가 부족한 영역, 특정 영역에 편중된 개념 분포, 기존 요소의 차원 결손(시점 의존 값의 유효기간·이력 부재, lifecycle 미완결 구간, 통제 행위의 감사 증거 부재, 병행 관리 값의 단일 권위 지정 부재).

### Assertion type

부재 진술: "도메인의 X 하위 영역이 시스템에 표현되어 있지 않다", "업계 표준 대비 Y 범주가 누락되었다".

## Core questions

- 도메인의 주요 하위 영역 중 시스템에 표현되지 않은 것이 있는가?
- 업계 표준/프레임워크 대비 누락된 개념 범주가 있는가?
- 상위 개념은 있으나 하위 세분화가 부족한 영역이 있는가?
- 개념 분포가 특정 영역에 편중되어 있는가?
- 시점 의존 값(등급, 상태, 계수, 단가 등)에 유효기간·이력 개념이 있어 과거 시점의 값을 재구성할 수 있는가?
- 상태를 갖는 요소의 lifecycle이 도입부터 종료(보관·폐기·단종)까지 전 구간을 커버하는가? 종결 상태 이후의 정정·재발행 사건이 상태 의미와 모순 없이 수용되는가?
- 통제가 필요한 행위(승인, 수동 조정, 통보)에 행위자·시각·근거를 추적할 증거 개념이 있는가?
- 복수 시스템·장부에 걸쳐 관리된다고 서술된 값에 단일 원본(권위) 지정이 있는가?

## Domain examples

- Software: 에러 처리는 정의되어 있으나 복구 전략이 부재; 인증은 있으나 인가 프레임워크가 누락; 상태 모델에 보관·폐기 등 종료 구간이 부재
- Law: 권리는 명시되어 있으나 구제 수단이 불충분; 본칙은 있으나 경과 조치가 누락
- Accounting: 수익 계정은 세분화되어 있으나 비용 계정이 뭉뚱그려져 있음; 국내 기준만 있고 해외 기준이 누락
