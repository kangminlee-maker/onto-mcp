# commerce-performance-marketing-kr Domain — System Verification Questions

이 문서는 국내 커머스 성과 마케팅 시스템이 올바르게 구조화되었는지 검증하기 위한 질문 목록이다.

분류 축: **검증 관심사(verification concern)** — 질문이 범위, 상품경제성, 채널, 측정, 의사결정, 준수 중 무엇을 검증하는지에 따른 분류.

우선순위:

- **P1** — 어떤 커머스 성과 마케팅 검토에서도 반드시 답할 수 있어야 한다.
- **P2** — 운영 시스템이라면 답할 수 있어야 한다.
- **P3** — 성숙한 운영 또는 고도화 단계에서 답할 수 있어야 한다.

## CQ ID System

| Prefix | Concern Area | Aligned Sub-Area |
|---|---|---|
| CQ-SC | Scope and Commerce Context | 판매 환경과 범위 |
| CQ-UE | Unit Economics | 거래 대상·마진·공급 제약 |
| CQ-AC | Acquisition Channel | 유입 투자와 채널 |
| CQ-OD | Organic Discovery | SEO·AEO·GEO·플랫폼 검색 |
| CQ-MA | Measurement and Attribution | 측정·어트리뷰션 |
| CQ-DC | Decision Control | 예산·실험·운영 판단 |
| CQ-CR | Customer and Retention | 고객 상태·CRM·재구매 |
| CQ-CO | Compliance | 국내 규제·플랫폼 정책 |
| CQ-GV | Governance | 운영 권위·책임 |

## 1. Scope and Commerce Context (CQ-SC)

- **CQ-SC-01** [P1] 판매 환경 유형이 자사몰, 스마트스토어, 마켓플레이스, 쿠팡, 리테일 미디어, 혼합 환경 중 무엇인지 명시되어 있는가?
  - 검증 기준: PASS if `commerce_type`이 존재하고 주 주문 발생 채널이 식별됨. FAIL if 광고 채널만 있고 판매 환경이 없음.

- **CQ-SC-02** [P1] 이 시스템의 1차 성과가 주문·결제·정산 가능한 단위 거래인지 명확한가?
  - 검증 기준: PASS if 최종 전환이 정산 가능한 주문이고 주문별 결제액·비용·마진·환불을 계산할 수 있음. FAIL if 상담, 설치, 활성 이용, 구독 해지율, 계약 갱신 같은 다른 도메인 KPI가 1차 KPI임.

- **CQ-SC-03** [P1] 웹, 앱, 플랫폼 내부 구매, 혼합 여정 중 어떤 구매 여정을 다루는지 명시되어 있는가?
  - 검증 기준: PASS if 구매 여정 유형과 추적 방식이 연결됨. FAIL if 웹/앱/플랫폼 내부 전환을 하나로 취급함.

- **CQ-SC-04** [P2] 주 판매 채널과 보조 판매 채널의 주문·정산 권위가 분리되어 있는가?
  - 검증 기준: PASS if 채널별 주문 데이터와 정산 데이터의 권위가 표시됨. FAIL if 모든 채널 결제액을 하나의 플랫폼 리포트로 통합함.

## 2. Unit Economics (CQ-UE)

- **CQ-UE-01** [P1] 목표 ROAS 또는 광고 효율 기준이 거래 대상별 원가·권리 비용, 수수료, 배송비 또는 제공 비용, 프로모션 비용에서 파생되는가?
  - 검증 기준: PASS if 손익분기 ROAS 또는 기여이익 기준이 존재함. FAIL if 목표 ROAS가 경험값 또는 플랫폼 권장값만으로 정해짐.

- **CQ-UE-02** [P1] 광고 기여 결제액, 확정 주문 결제액, 정산 기준 결제액이 구분되어 있는가?
  - 검증 기준: PASS if 플랫폼 광고 기여 결제액, 주문 DB 결제액, 정산 기준 결제액이 구분됨. FAIL if 광고 전환 매출이라는 관습 표현을 최종 결제액 또는 회계상 매출로 사용함.

- **CQ-UE-03** [P1] 입력의 `매출`이 결제액 기반 관습 표현인지, 회계상 발생주의 매출인지 판정되어 있는가?
  - 검증 기준: PASS if `매출` 필드마다 결제액, 광고 기여 결제액, 정산 기준 결제액, 회계상 매출 중 하나로 금액 기준이 표시됨. FAIL if `매출`을 무자격으로 출력하거나 결제액과 회계상 매출을 같은 값으로 취급함.

- **CQ-UE-04** [P1] 취소, 환불, 반품, 교환이 ROAS와 마진 판단에 반영되는가?
  - 검증 기준: PASS if 구매 후 보정 이벤트가 주문과 연결됨. FAIL if 구매완료 이후 상태 변화가 성과에서 제외됨.

- **CQ-UE-05** [P1] 결제액 ROAS가 높아도 기여이익이 음수인 경우를 차단할 수 있는가?
  - 검증 기준: PASS if 기여이익 또는 마진 제한 지표가 예산 판단에 포함됨. FAIL if ROAS만으로 증액 가능함.

- **CQ-UE-06** [P2] 재고 또는 공급 제약이 캠페인 예산 판단에 연결되어 있는가?
  - 검증 기준: PASS if 품절·재고 부족·접근권 제공 불가·좌석 제한·라이선스 제한 시 증액 차단 또는 경고가 있음. FAIL if 판매 가능 상태와 광고 운영이 분리됨.

- **CQ-UE-07** [P2] 쿠폰, 포인트, 무료배송, 사은품 비용의 부담 주체가 명시되어 있는가?
  - 검증 기준: PASS if 판매자 부담과 플랫폼 부담이 분리됨. FAIL if 할인 비용을 결제액 상승으로만 처리함.

- **CQ-UE-08** [P3] 상품군별 환불·반품률과 마진 차이를 반영해 목표 ROAS를 다르게 설정하는가?
  - 검증 기준: PASS if 카테고리 또는 SKU별 목표가 다름. FAIL if 모든 상품에 동일 목표 ROAS를 적용함.

## 3. Acquisition Channel (CQ-AC)

- **CQ-AC-01** [P1] 유입 투자 유형이 유료, 보유, 자연, CRM, 제휴, 인플루언서, 혼합 중 무엇인지 명시되어 있는가?
  - 검증 기준: PASS if `acquisition_type`이 존재함. FAIL if Paid/Non-paid 이분법만 있음.

- **CQ-AC-02** [P1] Non-paid 유입의 비용 범위가 직접 매체비 없음으로만 해석되고, 운영비·제작비·할인비 가능성이 분리되어 있는가?
  - 검증 기준: PASS if 직접 매체비와 기타 비용이 분리됨. FAIL if 자연·보유 유입을 무료로 처리함.

- **CQ-AC-03** [P1] 광고 채널이 플랫폼명이나 Paid/Non-paid만이 아니라 노출 방식, 미디어 포맷, 노출 위치, 노출 시점으로 분해되어 있는가?
  - 검증 기준: PASS if `exposure_method`, `media_format`, `placement`, `exposure_moment`가 존재함. FAIL if 플랫폼명 또는 Paid/Non-paid만으로 광고 채널을 정의함.

- **CQ-AC-04** [P1] 신규 고객 캠페인, 리타게팅, CRM, 브랜드 검색이 분리되어 있는가?
  - 검증 기준: PASS if 고객 상태 또는 캠페인 목적별 분리 리포트가 있음. FAIL if 모두 같은 ROAS로 비교함.

- **CQ-AC-05** [P2] Search Ad와 Display Ad가 고객 의도와 노출 맥락 기준으로 분리되어 있는가?
  - 검증 기준: PASS if 검색 의도 기반 노출과 지면·콘텐츠 기반 노출이 분리됨. FAIL if 검색광고와 DA를 같은 paid 광고 평균으로 비교함.

- **CQ-AC-06** [P2] DA 내부에서 이미지 단독, 이미지+텍스트, 캐러셀, 영상, 네이티브 콘텐츠 포맷이 분리되어 있는가?
  - 검증 기준: PASS if DA의 `media_format`이 구체적으로 표시됨. FAIL if 모든 DA를 하나의 포맷으로 집계함.

- **CQ-AC-07** [P2] 노출 위치가 검색 결과, 상품상세, 피드, 영상 지면, 메시지함, 푸시 등으로 구분되어 있는가?
  - 검증 기준: PASS if `placement`별 성과를 분리할 수 있음. FAIL if 플랫폼 전체 성과만 있음.

- **CQ-AC-08** [P2] 노출 시점이 능동 검색, 상품 비교, 콘텐츠 소비, 리타게팅, CRM 생애주기 등으로 구분되어 있는가?
  - 검증 기준: PASS if `exposure_moment`가 표시됨. FAIL if 구매 의도 단계가 다른 접점을 같은 기대 전환율로 평가함.

- **CQ-AC-09** [P2] 제휴·인플루언서 채널의 링크, 쿠폰코드, 커미션, 광고 표시가 성과와 연결되어 있는가?
  - 검증 기준: PASS if 파트너 ID와 정산·표시 근거가 있음. FAIL if 기여 결제액만 있고 대가 관계나 비용이 없음.

- **CQ-AC-10** [P2] 플랫폼 자연 유입 결제액과 광고 기여 결제액이 분리되어 있는가?
  - 검증 기준: PASS if 자연 노출 기여 결제액과 광고 기여 결제액이 별도임. FAIL if 자연 성과를 광고 성과로 귀속함.

- **CQ-AC-11** [P3] 광고가 브랜드 검색량, 리뷰, 플랫폼 랭킹 등 비광고 유입에 미치는 간접 효과를 별도로 관찰하는가?
  - 검증 기준: PASS if 간접 효과 관찰 지표가 있음. FAIL if 모든 증가분을 마지막 클릭 채널에 귀속함.

- **CQ-AC-12** [P1] 쇼핑광고, 카탈로그 광고, 리테일 미디어에서 상품 피드·카탈로그·랜딩의 가격, 재고, 상품 ID가 정합한가?
  - 검증 기준: PASS if `channel_product_id`, `catalog_item_id`, `event_item_id`, 랜딩 가격·재고 상태가 연결됨. FAIL if 피드 반려, 가격 불일치, 상품 ID 불일치를 광고 성과 문제로만 해석함.

## 4. Organic Discovery (CQ-OD)

- **CQ-OD-01** [P1] 검색 자연 노출이 SEO, 플랫폼 SEO, AEO, GEO, 소셜 검색 중 무엇인지 분리되어 있는가?
  - 검증 기준: PASS if `organic_discovery_type`이 존재함. FAIL if 모든 자연 발견을 SEO 또는 organic으로만 묶음.

- **CQ-OD-02** [P1] AEO/GEO 성과가 일반 검색 클릭이나 직접 ROAS와 분리되어 측정되는가?
  - 검증 기준: PASS if 답변 노출, 인용, 언급, 추천 문맥, 후속 브랜드 검색, assisted conversion이 구분됨. FAIL if AI 답변 언급을 직접 구매 성과로 확정함.

- **CQ-OD-03** [P1] 생성형 AI 응답에서의 언급·인용이 증분 구매 효과로 해석되기 전에 비교 근거가 있는가?
  - 검증 기준: PASS if 쿼리군 추적, 전후 비교, 홀드아웃, 지역·기간 분리, 브랜드 검색량 변화 중 하나 이상이 있음. FAIL if 단일 캡처나 일회성 언급으로 인과를 주장함.

- **CQ-OD-04** [P2] AEO를 위한 답변 추출 가능 구조가 존재하는가?
  - 검증 기준: PASS if 질문형 구조, 짧은 직접 답변, 표·목록·FAQ, 구조화 데이터, 근거 문장이 있음. FAIL if 장문 콘텐츠만 있고 답변 단위가 없음.

- **CQ-OD-05** [P2] GEO를 위한 엔티티 일관성과 근거 가능 주장이 관리되는가?
  - 검증 기준: PASS if 브랜드·상품·가격·정책·리뷰·효능 주장이 자사몰, 플랫폼, 외부 리뷰, 구조화 데이터에서 충돌하지 않음. FAIL if AI가 참조할 표면마다 정보가 다름.

- **CQ-OD-06** [P2] 플랫폼 SEO가 일반 SEO와 분리되어 있는가?
  - 검증 기준: PASS if 상품명, 카테고리, 속성, 이미지, 가격, 리뷰, 배송, 판매 가능 상태를 플랫폼 검색 기준으로 관리함. FAIL if 자사몰 SEO만 있고 마켓플레이스 검색 최적화가 없음.

- **CQ-OD-07** [P3] AEO/GEO 측정 스냅샷에 엔진, 지역, 시점, 프롬프트, 쿼리군, 인용 출처가 보존되는가?
  - 검증 기준: PASS if 측정 조건이 재현 가능함. FAIL if AI 응답 캡처만 있고 조건이 없음.

## 5. Measurement and Attribution (CQ-MA)

- **CQ-MA-01** [P1] 구매 이벤트가 주문번호, 금액, 상품 ID, 수량과 연결되어 있는가?
  - 검증 기준: PASS if 구매 이벤트와 주문 DB 매칭 가능. FAIL if 구매 카운트만 있음.

- **CQ-MA-02** [P1] 전환 기간과 어트리뷰션 모델이 플랫폼별로 명시되어 있는가?
  - 검증 기준: PASS if 각 플랫폼의 전환 기간과 모델이 표시됨. FAIL if 플랫폼별 전환을 같은 기준으로 비교함.

- **CQ-MA-03** [P1] 플랫폼 간 중복 전환을 주문번호 또는 다른 식별자로 제거할 수 있는가?
  - 검증 기준: PASS if 중복 제거 규칙이 있음. FAIL if 채널별 광고 기여 결제액을 단순 합산함.

- **CQ-MA-04** [P1] 어트리뷰션과 증분성이 구분되어 있는가?
  - 검증 기준: PASS if 기여와 인과 증가분 표현이 분리됨. FAIL if 플랫폼 광고 기여 결제액을 증분 결제액으로 표현함.

- **CQ-MA-05** [P2] 조회 기여와 클릭 기여가 분리되어 보고되는가?
  - 검증 기준: PASS if view-through와 click-through가 분리됨. FAIL if 합산 전환만 있음.

- **CQ-MA-06** [P2] 서버 이벤트 또는 주문 DB 연결로 브라우저·앱 추적 유실을 보완하는가?
  - 검증 기준: PASS if 서버 이벤트나 주문 매칭 경로가 있음. FAIL if 클라이언트 픽셀만 의존함.

- **CQ-MA-07** [P3] 홀드아웃, 지역 분리, 기간 분리, 예산 중단 테스트 등 증분성 검증 구조가 있는가?
  - 검증 기준: PASS if 최소 하나 이상의 비교 구조가 있음. FAIL if 어트리뷰션만으로 인과를 주장함.

- **CQ-MA-08** [P1] 의사결정에 사용한 지표의 측정 신뢰도와 허용된 결정 범위가 표시되는가?
  - 검증 기준: PASS if 플랫폼 리포트, 서버 이벤트, 주문 DB, 정산 DB, 증분성 테스트가 구분되고 각 지표의 사용 한계가 표시됨. FAIL if 낮은 신뢰도 지표로 손익 또는 인과 효과를 확정함.

- **CQ-MA-09** [P1] 앱 설치·실행·구매 성과가 MMP, SDK, SKAN·AdAttributionKit, 주문 DB 권위별로 분리되어 있는가?
  - 검증 기준: PASS if 설치 어트리뷰션, 앱 이벤트, 집계 포스트백, 확정 주문·정산 데이터가 구분됨. FAIL if 앱 설치 또는 집계 포스트백을 구매 결제액으로 확정함.

- **CQ-MA-10** [P2] 구매·장바구니·조회 이벤트의 상품 ID가 상품 피드와 주문 상품 ID에 매칭되는가?
  - 검증 기준: PASS if 이벤트 상품 ID, 카탈로그 상품 ID, 주문 상품 ID 매칭 규칙이 있음. FAIL if 상품 단위 리타게팅이나 ROAS를 ID 매칭 없이 계산함.

## 6. Decision Control (CQ-DC)

- **CQ-DC-01** [P1] 캠페인 증액, 유지, 축소, 중단 조건이 사전에 정의되어 있는가?
  - 검증 기준: PASS if 의사결정 규칙과 재검토 시점이 있음. FAIL if 운영자가 임의 판단함.

- **CQ-DC-02** [P1] 예산 증액 전에 마진, 재고 또는 공급 제약, 환불·반품률, 준수 위험을 확인하는 제한 지표가 있는가?
  - 검증 기준: PASS if guardrail metrics가 있음. FAIL if 목표 ROAS만 봄.

- **CQ-DC-03** [P2] 소재 테스트와 오퍼 테스트가 분리되어 있는가?
  - 검증 기준: PASS if 가격·쿠폰·소재 변경 효과를 분리할 수 있음. FAIL if 쿠폰 추가 후 소재 성과로 판단함.

- **CQ-DC-04** [P2] 가격, 배송, 리뷰, 재고, 상세페이지 변경이 성과 비교에 미친 영향을 기록하는가?
  - 검증 기준: PASS if 주요 외부 변수 변경 로그가 있음. FAIL if 변경 전후를 직접 비교함.

- **CQ-DC-05** [P3] 자동 입찰 또는 목표 ROAS 캠페인의 학습 기간과 변경 이력을 관리하는가?
  - 검증 기준: PASS if 목표값·예산·피드 변경 기록이 있음. FAIL if 변경 직후 성과로만 판단함.

## 7. Customer and Retention (CQ-CR)

- **CQ-CR-01** [P1] 신규 고객 판정 기준이 주문 DB 또는 CRM 기준으로 명시되어 있는가?
  - 검증 기준: PASS if 첫 구매 기준과 기간이 있음. FAIL if 플랫폼 신규 사용자만으로 CAC를 계산함.

- **CQ-CR-02** [P1] CRM 발송 대상에서 수신거부 고객이 차단되는가?
  - 검증 기준: PASS if 수신거부가 발송 대상보다 높은 차단 권위를 가짐. FAIL if 수신거부 반영이 수동 또는 불명확함.

- **CQ-CR-03** [P1] LTV를 사용하는 경우 반복구매율, 구매 간격, 마진 유지, 할인 의존도 근거가 있는가?
  - 검증 기준: PASS if 코호트 근거가 있음. FAIL if 미래 LTV 가정만 있음.

- **CQ-CR-04** [P2] 휴면·재활성화 기준이 상품 구매 주기와 연결되어 있는가?
  - 검증 기준: PASS if 상품군별 휴면 기준이 있음. FAIL if 전체 고객에 동일 휴면 기간을 적용함.

- **CQ-CR-05** [P2] CRM 성과가 신규 획득 성과와 분리되어 있는가?
  - 검증 기준: PASS if 기존 고객 결제액과 신규 고객 결제액이 분리됨. FAIL if CRM 기여 결제액으로 CAC를 낮춰 계산함.

## 8. Compliance (CQ-CO)

- **CQ-CO-01** [P1] 픽셀, SDK, 서버 이벤트, 맞춤형 광고에 필요한 개인정보·행태정보 고지와 거부 구조가 확인되어 있는가?
  - 검증 기준: PASS if 처리방침, 고지, 거부권 확인이 있음. FAIL if 플랫폼 설치만 확인함.

- **CQ-CO-02** [P1] 문자, 이메일, 앱 푸시, 카카오 메시지 등 광고성 정보 발송에 수신동의와 수신거부 구조가 있는가?
  - 검증 기준: PASS if 채널별 동의와 거부가 기록됨. FAIL if 발송 가능 여부가 불명확함.

- **CQ-CO-03** [P1] 가격, 할인율, 최저가, 효능, 비교, 후기 표현의 실증 근거가 있는가?
  - 검증 기준: PASS if 소재별 근거가 연결됨. FAIL if 표현만 있고 근거가 없음.

- **CQ-CO-04** [P1] 인플루언서, 리뷰, 공동구매 콘텐츠에 대가 관계 표시가 있는가?
  - 검증 기준: PASS if 광고 표시 또는 협찬 표시가 확인됨. FAIL if 성과 링크만 있고 표시 근거가 없음.

- **CQ-CO-05** [P2] 상품상세와 랜딩에 배송, 환불, 청약철회, 판매자 정보, 추가 비용이 명확히 고지되어 있는가?
  - 검증 기준: PASS if 거래조건 고지가 확인됨. FAIL if 구매 유도 정보만 있음.

- **CQ-CO-06** [P2] 플랫폼 광고 심사 정책과 금지 품목·업종 제한을 캠페인 시작 전에 확인하는가?
  - 검증 기준: PASS if 사전 심사 체크가 있음. FAIL if 반려 후 수정만 함.

- **CQ-CO-07** [P1] 캠페인 시작 전에 필요한 준수 증빙이 없으면 시작이 차단되는가?
  - 검증 기준: PASS if 동의, 수신거부, 실증 근거, 광고 표시, 거래조건 스냅샷 중 필요한 증빙이 없을 때 보류됨. FAIL if 증빙 없이 사후 보완으로 시작함.

- **CQ-CO-08** [P1] 수신거부, 맞춤형 광고 거부, 앱 푸시 해제 같은 차단 신호가 발송·타겟팅 대상보다 우선하는가?
  - 검증 기준: PASS if 차단 목록이 세그먼트 조건보다 높은 권위를 가짐. FAIL if 캠페인 대상에 차단 신호 고객이 포함될 수 있음.

## 9. Governance (CQ-GV)

- **CQ-GV-01** [P1] 광고비, 상품 가격, 쿠폰, 재고, 데이터, 준수 책임자가 구분되어 있는가?
  - 검증 기준: PASS if 의사결정 책임이 명시됨. FAIL if 성과 하락 원인별 책임자가 없음.

- **CQ-GV-02** [P1] 의사결정 로그가 지표 권위 수준, 결정 이유, 재검토 시점을 기록하는가?
  - 검증 기준: PASS if 증액·축소·중단 로그가 있음. FAIL if 운영 변경 이력이 없음.

- **CQ-GV-03** [P2] 추적 오류, 품절, 정책 위반, 반품 급증 같은 사고에 대한 중단·복구 절차가 있는가?
  - 검증 기준: PASS if 사고 유형별 대응이 있음. FAIL if 담당자 판단에만 의존함.

- **CQ-GV-04** [P3] 새로운 플랫폼이나 채널을 추가할 때 데이터 권위, 비용 범위, 준수 기준을 등록하는 절차가 있는가?
  - 검증 기준: PASS if 신규 채널 온보딩 체크가 있음. FAIL if 채널별 임의 운영으로 시작함.
