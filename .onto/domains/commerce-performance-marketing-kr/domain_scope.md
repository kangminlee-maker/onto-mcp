# commerce-performance-marketing-kr Domain — Domain Scope Definition

이 문서는 대한민국 온라인 커머스 환경에서 성과 마케팅 시스템이 "반드시 다루어야 하는데 빠진 것"을 식별하는 기준 문서이다.
범위는 정산 가능한 주문 단위 거래를 중심으로 한 국내 커머스 성과 마케팅이며, 광고 플랫폼 리포트가 아니라 확정 주문, 주문 결제액, 취소·환불·반품, 정산, 거래 대상별 마진, 재고 또는 공급 제약까지 연결된 의사결정 구조를 기준으로 한다.

이 패키지는 독립적으로 작동해야 한다. 다른 도메인 문서의 내용을 참조하거나 가져오지 않으며, 패키지 내부 문서끼리만 역할을 나눈다.

## 커머스 정의

이 도메인에서 **커머스**는 고객이 특정 거래 대상을 선택하고, 가격·혜택·거래조건을 확인한 뒤, 주문·결제·정산 가능한 단위 거래를 발생시키는 비즈니스이다.

커머스 여부는 판매 대상의 물성이 아니라 성과 판단 단위로 결정한다. 실물 상품, 디지털 파일, 콘텐츠, 이용권, 클래스, 리포트, 템플릿 모두 주문 단위로 판매되고 주문별 결제액·비용·마진·환불을 계산한다면 커머스이다. 반대로 판매 대상이 콘텐츠여도 반복 과금, 해지, 잔존율, 활성 이용, 계약 갱신이 1차 성과라면 이 도메인의 커머스가 아니다.

커머스 판정 기준:

- 1차 전환이 상담, 설치, 가입, 이용 활성화가 아니라 주문 또는 구매이다.
- 성과 금액 권위가 주문, 결제, 정산 데이터에 연결된다.
- 성과 판단이 거래 대상별 결제액, 비용, 마진, 환불·반품, 프로모션 비용으로 내려갈 수 있다.
- 고객 생애가 중요하더라도 1차 의사결정은 주문 단위 손익과 획득 효율에서 시작한다.
- 재고는 필수 조건이 아니다. 실물 상품은 재고·배송 제약을 갖고, 디지털·콘텐츠 거래는 접근권, 좌석, 라이선스, 제공 가능 기간, 환불 조건 같은 공급 제약을 가질 수 있다.

### 매출 용어 사용 원칙

이 도메인에서 마케터가 관습적으로 말하는 `매출`은 대체로 회계상 발생주의 매출이 아니라 주문·결제·정산 데이터에 기반한 결제액이다. 따라서 입력 자료의 `매출`은 문맥에 따라 `결제액을 매출이라고 부르는 관습적 표현`인지, 회계상 매출 인식을 뜻하는지 판정해야 한다.

LLM 출력은 반드시 둘을 구분한다. 성과 마케팅 맥락의 금액은 `결제액`, `광고 기여 결제액`, `정산 기준 결제액`처럼 쓰고, 발생주의 기준의 회계 매출은 `회계상 매출` 또는 `발생주의 매출`로 쓴다. 관습적 표현을 설명할 때만 `매출(실무상 결제액 의미)`처럼 병기한다.

## 포함 범위

분류 축: **커머스 성과 판단 단위(commerce performance decision unit)** — 성과를 판단할 때 어떤 주문·거래 대상 단위를 기준으로 결제액, 비용, 마진, 공급 제약, 고객 상태를 묶는지에 따른 분류.

이 도메인은 다음 상황을 포함한다.

- 국내 소비자를 대상으로 정산 가능한 주문 단위 거래 대상을 판매하는 온라인 커머스
- 자사몰, 스마트스토어, 오픈마켓, 쿠팡, 종합몰, 버티컬몰, 라이브커머스, 리테일 미디어, 카카오 채널·톡스토어, 검색·쇼핑·소셜 광고가 결합된 판매 운영
- 광고비를 직접 투입하는 유료 획득, 보유 채널을 활용하는 CRM, 플랫폼 내 자연 노출, 제휴·인플루언서·콘텐츠 유입이 함께 작동하는 성과 구조
- 상품·콘텐츠 단위의 결제액, 주문, 취소, 환불, 반품, 교환, 정산, 원가, 수수료, 배송비 또는 제공 비용, 쿠폰·프로모션 비용, 재고 또는 공급 제약을 고려한 마케팅 의사결정
- 웹 기반 구매 여정, 앱 기반 구매 여정, 플랫폼 내부 스토어 여정, 웹·앱·플랫폼이 섞인 구매 여정
- 픽셀, SDK, 서버 이벤트, GA4 전자상거래 이벤트, 광고 플랫폼 전환 추적, 주문 DB, 정산 DB, CRM 데이터를 결합한 성과 측정
- 국내 개인정보, 온라인 맞춤형 광고, 광고성 정보 전송, 표시·광고, 추천·보증 표시, 전자상거래 소비자보호와 관련된 운영 준수

## 제외 범위

다음은 이 도메인의 직접 범위가 아니다. 필요하면 별도 도메인으로 분리한다.

- 구독 서비스, SaaS, 멤버십, 콘텐츠 서비스처럼 반복 과금·해지·잔존율·활성 이용이 1차 성과인 비즈니스
- 앱 설치, 앱 활성화, 리텐션, 인앱 결제를 중심으로 한 앱 성장 마케팅
- 상담 신청, 견적 문의, 예약, 영업 파이프라인 전환을 중심으로 한 리드 제너레이션
- 브랜드 인지도, PR, 순수 콘텐츠 브랜딩처럼 구매 성과와 직접 연결하지 않는 활동
- 상품 기획, 제조, 소싱, 물류 운영 자체. 단, 상품·콘텐츠 마진, 재고·공급 제약, 배송비·제공 비용, 환불·반품률이 마케팅 판단에 영향을 줄 때는 포함한다.
- 일반 회계, 세무, 재무제표 작성. 단, 마케팅 문서의 결제액 기반 `매출` 표현과 회계상 매출 인식이 혼동되는 경우의 용어 판정 기준은 포함한다.
- 해외 판매, 수출, 역직구, 글로벌 플랫폼 규정. 국내 고객·국내 플랫폼 운영에 직접 연결되는 경우만 포함한다.

| 자연 발견 최적화 유형 | `seo`, `platform_seo`, `aeo`, `geo`, `social_search_optimization`, `marketplace_search_optimization`, `local_discovery_optimization` | 검색 결과, 플랫폼 내부 검색, 답변형 결과, 생성형 AI 응답, 소셜 검색에서 발견되는 방식이 달라진다. |

### 축 적용 원칙

- 커머스 도메인에서 ROAS는 기본 지표이지만 최종 판단 지표가 아닐 수 있다. 거래 대상별 원가·권리 비용, 수수료, 배송비 또는 제공 비용, 쿠폰, 환불·반품·취소, 재고 또는 공급 제약 비용을 반영한 기여이익 기준이 우선될 수 있다.
- 반복구매 근거가 없는 커머스에서 LTV를 1차 판단 기준으로 사용하면 안 된다. 반복구매 코호트, 재구매 주기, 마진 유지, 할인 의존도가 검증된 경우에만 보조 또는 확장 지표로 사용한다.
- 웹과 앱은 같은 구매 이벤트를 가질 수 있지만 추적 방식, 유실 경로, 딥링크, 로그인 식별, SDK·서버 이벤트 구조가 다르므로 같은 측정 구조로 취급하지 않는다.
- 앱 커머스에서 MMP, SKAN, AdAttributionKit, Firebase, 앱스토어 결제 이벤트는 서로 다른 측정 권위를 가진다. 집계·지연·익명화된 포스트백을 주문 DB의 확정 결제액으로 대체하지 않는다.
- 플랫폼 내부 스토어는 자사몰보다 랜딩·데이터·정산 통제력이 낮다. 플랫폼 리포트는 유용한 운영 신호이지만 확정 주문·정산·마진 권위를 대체하지 않는다.
- Paid / Non-paid는 단순 이분법으로 다루지 않는다. 보유 채널, 자연 노출, 제휴, 콘텐츠, 인플루언서도 제작비, 수수료, 기회비용, 중복 전환 비용을 가질 수 있다.
- 검색 자연 노출은 SEO만으로 한정하지 않는다. 검색 결과 목록 최적화는 SEO, 답변형 결과·스니펫·FAQ·음성 답변 최적화는 AEO, 생성형 AI 응답의 언급·인용·추천 가능성 최적화는 GEO로 분리한다.
- AEO와 GEO는 직접 매체비가 없을 수 있지만 무료 채널이 아니다. 콘텐츠 제작, 구조화 데이터, 제품 정보 정합성, 외부 신뢰 신호, 측정 리포트 구축 비용을 가진다.
- AEO/GEO 성과는 클릭 이전의 답변 노출, 인용, 브랜드 언급, 추천 문맥, 후속 브랜드 검색, 직접 유입, assisted conversion으로 나타날 수 있다. 이를 일반 SEO 세션이나 직접 전환만으로 축소하지 않는다.
- 광고 매체는 비용 축만으로 분류하지 않는다. 같은 paid 광고라도 검색 결과 텍스트 광고, 상품 카드형 쇼핑 광고, 디스플레이 이미지 광고, 이미지+텍스트 네이티브 광고, 숏폼 영상 광고는 노출 방식과 고객 의도가 다르다.
- Search Ad는 능동적 검색 의도를 포획하는 노출이고, Display Ad는 콘텐츠·피드·앱·웹 지면에서 탐색 중인 고객에게 노출되는 구조이다. 두 유형은 CTR, CVR, 신규 수요 창출, 리타게팅 의존도를 같은 기준으로 비교하지 않는다.
- DA는 하나의 포맷이 아니다. `image_only`, `image_text`, `carousel`, `short_form_video`, `long_form_video`, `native_content`처럼 포맷을 분리해야 소재 제작·심사·피로도·성과 해석이 가능하다.
- 쇼핑광고, 카탈로그 광고, 리테일 미디어는 상품 피드와 플랫폼 상품 정보의 정합성이 성과의 선행 조건이다. 가격, 재고, 상품 ID, 이미지, 카테고리, 랜딩 정보가 불일치하면 소재나 입찰 문제가 아니라 상품 데이터 문제로 먼저 판정한다.
- 어트리뷰션은 접점 기여 설명이며, 인과 효과의 증명은 아니다. 증분성을 주장하려면 홀드아웃, 지리·기간 분리, 예산 중단/증액 테스트 등 별도 근거가 필요하다.

## 주요 하위 영역

- 비용 구조: 광고비, 판매 수수료, PG 수수료, 플랫폼 수수료, 배송비, 포장비, 접근권 제공 비용, 콘텐츠 제작·권리 비용, 쿠폰·포인트, 제휴 수수료
- 마진 구조: 거래총이익, 기여이익, 주문당 공헌이익, SKU별 손익, 할인 후 마진
- 의사결정 기준: 목표 ROAS, 손익분기 ROAS, 기여 ROAS, MER, CAC, 신규 고객 획득 비용, 재고 회전 목적, 콘텐츠 단건 판매 회수 목적
- LTV 사용 제한: 반복구매 근거가 있을 때만 보조 지표로 인정

### 2. 판매 환경과 구매 여정

- 자사몰: 랜딩, 상품상세, 장바구니, 체크아웃, 결제 완료, 주문 DB, GA4 전자상거래 이벤트
- 스마트스토어·오픈마켓: 플랫폼 내부 전환, 검색·쇼핑 노출, 리뷰·찜·장바구니, 정산 리포트
- 쿠팡·리테일 미디어: 광고 전환 주문·판매, 직접·간접 전환, 목표 ROAS, 상품별 광고 운영
- 앱 커머스: SDK, 딥링크, 앱 내 구매, 푸시 수신동의, 앱과 웹 중복 식별
- 혼합 여정: 광고 클릭 후 앱 전환, 웹 탐색 후 플랫폼 구매, CRM 재방문 후 구매

### 3. 유입 투자 유형과 채널 운영

- 유료 매체: 검색광고, 쇼핑광고, 디스플레이, 소셜, 동영상, 리테일 미디어, 리타게팅
- 보유 매체: 자사몰, 앱 푸시, 카카오 채널, 문자, 이메일, 자사 콘텐츠, 멤버십
- 자연·플랫폼 유입: 검색 자연 노출, SEO, AEO, GEO, 플랫폼 랭킹, 리뷰, 찜, 장바구니, 추천 영역, 소셜 검색
- 제휴·인플루언서: 커미션, 할인코드, 공동구매, 라이브커머스, 협찬 표시
- 혼합 유입: 브랜드 검색 수요, CRM 재활성화, 리타게팅, 인플루언서 후속 검색이 중첩되는 구조
- 노출 방식: Search Ad, Display Ad, Shopping Listing Ad, Retail Media Ad, Social Feed Ad, Video Ad, Message Ad, Creator Native Ad
- 미디어 포맷: 텍스트, 이미지만, 이미지+텍스트, 상품 카드, 캐러셀, 숏폼 영상, 롱폼 영상, 라이브 영상, 리치 메시지, 네이티브 콘텐츠
- 노출 위치: 검색 결과, 쇼핑 결과, 상품상세, 카테고리 목록, 홈 피드, 소셜 피드, 스토리·릴스, 영상 스트림, 디스플레이 지면, 메시지함, 푸시, 크리에이터 콘텐츠
- 노출 시점: 능동 검색, 카테고리 탐색, 상품 비교, 콘텐츠 소비, 소셜 탐색, 방문 후 리타게팅, 장바구니·결제, CRM 생애주기, 시즌·이벤트, 구매 후

### 4. 캠페인·소재·오퍼

- 캠페인 목적: 신규 고객 획득, 기존 수요 회수, 재구매 유도, 객단가 상승, 재고 소진, 카테고리 확장
- 소재 단위: 상품 이미지, 썸네일, 숏폼, 배너, 검색 소재, 라이브·리뷰 콘텐츠, 상세페이지 메시지
- 오퍼 단위: 가격, 쿠폰, 무료배송, 사은품, 묶음 할인, 기간 한정, 플랫폼 지원 혜택
- 검증 단위: 소재별 CTR, 상품상세 진입률, 장바구니율, 구매율, 할인 후 마진, 반품률
- 금지 혼합: 클릭률이 좋은 소재와 이익이 좋은 소재를 같은 성공 기준으로 판정하지 않는다.

### 5. 추적·어트리뷰션·데이터 권위

- 이벤트 택소노미: 상품조회, 장바구니, 결제시작, 구매완료, 취소, 반품, 교환, 재구매
- 식별 구조: UTM, 클릭 ID, 쿠키, 로그인 ID, 기기 ID, 주문번호, 고객번호, 쿠폰코드
- 권위 계층: 광고 플랫폼 리포트 → 분석 도구 이벤트 → 서버 이벤트 → 주문 DB → 정산 DB → 증분성 테스트
- 어트리뷰션: 마지막 클릭, 데이터 기반, 조회 기여, 플랫폼별 기여, 중복 제거
- 데이터 품질: 누락, 중복, 지연, 환불 반영, 세션 끊김, 앱·웹 중복, 플랫폼 간 중복

### 6. 실험·학습·예산 의사결정

- 실험 구조: 소재 테스트, 오퍼 테스트, 랜딩 테스트, 예산 증감 테스트, 홀드아웃, 캠페인 중단 테스트
- 학습 기준: 동일 기간, 동일 상품·콘텐츠, 동일 오퍼, 동일 재고·접근권 조건, 동일 시즌성 조건을 최대한 맞춘다.
- 예산 배분: 목표 ROAS, 기여이익, 신규 고객 비중, 재고·공급 제약, 학습 필요성을 함께 반영한다.
- 중단 기준: 마진 손실, 추적 불안정, 재고 부족, 접근권 제공 오류, 환불·반품률 급증, 광고 정책 위반, 수신거부 리스크

### 7. CRM·재구매·리텐션

- CRM 채널: 카카오 채널 메시지, 알림톡·친구톡, 문자, 이메일, 앱 푸시, 멤버십 알림
- 고객 상태: 신규, 첫 구매, 재구매 가능, 휴면, 재활성화, VIP, 반품 위험군
- 재구매 판단: 상품 소모주기, 카테고리 반복성, 구매 간격, 할인 의존도, 마진 유지
- 수신동의·철회: 광고성 정보 전송, 수신거부, 야간 발송, 채널별 동의 근거
- 기존 수요 회수: CRM 성과를 신규 획득 성과와 섞지 않는다.

## 편향 감지 기준

- 자사몰과 플랫폼 스토어를 같은 데이터 통제 환경으로 취급하는 경우 → **판매 환경 혼합 편향**
- 단건 판매형 콘텐츠를 반복 과금형 콘텐츠 서비스와 같은 LTV·해지율 구조로 취급하는 경우 → **콘텐츠 비즈니스 모델 혼합 편향**
- 웹 구매와 앱 구매를 같은 추적 방식으로 취급하는 경우 → **구매 여정 혼합 편향**
- 플랫폼 ROAS만 보고 확정 주문, 취소, 반품, 정산, 마진을 확인하지 않는 경우 → **플랫폼 리포트 과신**
- 마케팅 문서의 `매출`을 회계상 발생주의 매출로 오인하거나, 결제액과 회계상 매출을 구분하지 않는 경우 → **매출-결제액 혼동**
- 결제액 ROAS는 높지만 쿠폰, 수수료, 배송비, 반품비, 원가를 제외하는 경우 → **마진 누락 편향**
- 반복구매 근거 없이 LTV를 1차 KPI로 사용하는 경우 → **미검증 LTV 편향**
- 신규 고객 캠페인과 리타게팅·CRM·브랜드 검색을 같은 효율로 비교하는 경우 → **수요 회수 혼합 편향**
- Search Ad, Display Ad, Shopping Ad, Video Ad를 플랫폼명만으로 묶어 같은 광고 채널처럼 비교하는 경우 → **노출 방식 혼합 편향**
- 이미지 배너, 이미지+텍스트 네이티브, 상품 카드, 숏폼 영상을 같은 DA 포맷으로 묶는 경우 → **미디어 포맷 혼합 편향**
- 검색 결과, 상품상세, 소셜 피드, 메시지함, 푸시처럼 고객 의도가 다른 노출 위치를 분리하지 않는 경우 → **노출 위치 누락**
- 능동 검색, 콘텐츠 소비, 리타게팅, 장바구니, CRM 생애주기처럼 노출 시점이 다른 접점을 같은 전환 기대치로 평가하는 경우 → **노출 시점 혼합 편향**
- Paid만 비용으로 보고 콘텐츠, 인플루언서, 제휴, CRM 제작·운영 비용을 0으로 보는 경우 → **무료 유입 착시**
- SEO, AEO, GEO를 모두 검색 자연 유입으로만 묶고 노출 표면과 측정 기준을 분리하지 않는 경우 → **자연 발견 유형 혼합 편향**
- 생성형 AI 응답에 브랜드가 언급되었다는 사실만으로 구매 증분 효과를 확정하는 경우 → **GEO 인과 과대해석**
- 답변형 결과에서 노출되었지만 클릭이 적다는 이유만으로 AEO 성과가 없다고 보는 경우 → **제로클릭 성과 누락**
- 광고 클릭 전 이미 구매 의도가 높았던 브랜드 검색·장바구니 고객까지 신규 획득으로 보는 경우 → **기존 수요 포획 편향**
- 할인·쿠폰이 만든 전환 상승을 상품·소재 개선으로 해석하는 경우 → **오퍼 효과 오인**
- 클릭률·조회수·찜·장바구니를 구매·마진보다 우선하는 경우 → **상단 퍼널 과대평가**
- 재고 부족, 품절, 접근권 제공 오류, 배송 지연, 가격 변경, 리뷰 하락을 마케팅 성과와 분리하지 않는 경우 → **운영 제약 누락**
- 인플루언서·리뷰·공동구매에서 광고 표시와 실증 근거를 확인하지 않는 경우 → **표시광고 준수 누락**
- 카카오 메시지, 문자, 이메일, 앱 푸시에서 수신동의·수신거부를 확인하지 않는 경우 → **광고성 정보 준수 누락**
- 맞춤형 광고와 리타게팅에서 행태정보 처리 고지와 거부권을 확인하지 않는 경우 → **개인정보 준수 누락**
- 쇼핑·카탈로그 광고 성과를 보면서 상품 피드의 가격, 재고, 상품 ID, 랜딩 정합성을 확인하지 않는 경우 → **상품 데이터 권위 누락**
- 앱 설치, SDK 구매 이벤트, SKAN·AdAttributionKit 포스트백, 주문 DB 구매를 같은 전환으로 합치는 경우 → **앱 측정 권위 혼동**

## 패키지 내부 문서 계약

- `domain_scope.md`는 커머스 성과 마케팅의 적용 범위, 제외 범위, 변동 축, 필수 하위 영역을 정한다.
- `concepts.md`는 이 범위에서 사용되는 용어와 해석 원칙을 정의한다.
- `structure_spec.md`는 캠페인, 거래 대상, 주문, 고객, 데이터 권위, 리포트 구조의 필수 관계를 정한다.
- `logic_rules.md`는 지표 계산, 어트리뷰션, 증분성, 예산 판단, 준수 판단의 규칙을 정한다.
- `dependency_rules.md`는 상품·콘텐츠·재고·공급 제약·프로모션·데이터·채널 간 의존과 충돌 해결 우선순위를 정한다.
- `competency_qs.md`는 이 패키지가 답할 수 있어야 하는 검증 질문을 제공한다.
- `extension_cases.md`는 새 플랫폼, 새 채널, 새 측정 방식, 새 규제 상황이 생길 때 확장 방법을 정한다.
- `conciseness_rules.md`는 문서가 불필요하게 커지지 않도록 개념 중복, 지표 중복, 플랫폼 세부사항의 수용 기준을 정한다.
- 이 패키지의 문서는 다른 도메인 패키지를 참조하지 않는다. 필요한 개념은 이 패키지 안에서 직접 정의한다.
