# commerce-performance-marketing-kr Domain — Dependency Rules

이 문서는 국내 커머스 성과 마케팅에서 상품, 채널, 고객, 데이터, 준수 요소가 서로 어떤 의존 관계를 갖는지 정의한다.
성과 판단은 광고 지표 하나로 끝나지 않으며, 주문·정산·마진·재고 또는 공급 제약·고객 상태·법률 제약이 함께 충족되어야 한다.

분류 축: **의존 원천(dependency source)** — 어떤 요소가 다른 판단의 선행 조건 또는 우선 권위가 되는지에 따른 분류.

## 권위 우선순위

최종 손익 판단의 권위 순서는 다음과 같다.

1. 법률·플랫폼 준수 제약
2. 주문·결제·정산 확정 데이터
3. 거래 대상별 원가·권리 비용·수수료·배송비 또는 제공 비용·프로모션 비용
4. 재고·공급 제약·배송·환불·반품 운영 상태
5. 고객 상태와 CRM 동의 데이터
6. 서버 이벤트와 내부 분석 이벤트
7. 광고 플랫폼 리포트
8. 소재·채널 운영 가설

우선순위 규칙:

- 준수 위반 위험은 성과 지표보다 우선한다.
- 정산 확정 데이터는 광고 플랫폼의 광고 기여 결제액보다 높은 손익 권위를 가진다.
- 회계상 매출은 재무보고 권위이고, 결제액은 성과 마케팅 권위이다. 성과 마케팅 손익 판단에서 회계상 매출을 기본 금액으로 쓰지 않는다.
- 거래 대상 경제성은 목표 ROAS와 예산 증액 판단의 선행 조건이다.
- 재고 또는 공급 제약과 배송·제공 상태는 광고 증액 가능 여부의 선행 조건이다.
- 고객 상태 데이터는 CAC, 신규 고객 결제액, CRM 성과의 선행 조건이다.

## 비즈니스 목표 의존

- `business_goal = payment_growth`이면 결제액, 주문수, 신규 고객, MER을 보되 마진 제한 지표가 필요하다. 기존 자료의 `revenue_growth`는 결제액 성장 의미인지 회계상 매출 성장 의미인지 판정한다.
- `business_goal = contribution_profit_growth`이면 기여이익, 기여 ROAS, 거래 대상군별 마진이 1차 권위가 된다.
- `business_goal = new_customer_acquisition`이면 신규 고객 판정과 기존 고객 제외 구조가 선행되어야 한다.
- `business_goal = repeat_purchase`이면 고객 식별, 구매 이력, 수신동의, 상품 소모주기가 선행되어야 한다.
- `business_goal = inventory_clearance`이면 SKU별 재고, 할인 후 마진, 소진 기한이 선행되어야 한다.
- `business_goal = single_purchase_recovery`이면 주문 단위 결제액, 원가·권리 비용, 환불률, 제공 비용, 광고비 회수 기간이 선행되어야 한다.
- 목표가 복수이면 우선순위 또는 모드 전환 조건을 명시해야 한다.

## 상품 경제성 의존

- 목표 ROAS는 거래 대상별 원가·권리 비용, 수수료, 배송비 또는 제공 비용, 쿠폰, 환불·반품률, 판매가에 의존한다.
- 판매가가 바뀌면 목표 ROAS와 전환율 기준을 재계산한다.
- 원가 또는 수수료가 바뀌면 기존 캠페인의 손익 판단을 재검토한다.
- 무료배송 정책이 바뀌면 주문당 기여이익과 손익분기 ROAS가 바뀐다.
- 쿠폰 또는 포인트가 추가되면 순결제액, 프로모션 비용, 마진 판단이 바뀐다.
- 반품률이 높은 상품군은 구매 전환 성과보다 반품 반영 후 성과에 의존한다.
- SKU 품절 또는 재고 부족은 해당 SKU 캠페인 예산 증액을 차단하거나 제한한다.
- 재고가 없는 디지털·콘텐츠 거래도 접근권 제공 불가, 좌석 제한, 라이선스 제한, 판매 가능 기간 종료가 있으면 예산 증액을 차단하거나 제한한다.

## 판매 환경 의존

- 자사몰 성과는 내부 태그, 서버 이벤트, 주문 DB, 정산 DB에 의존한다.
- 스마트스토어와 오픈마켓 성과는 플랫폼 리포트와 정산 리포트에 의존한다.
- 쿠팡 성과는 광고 전환 판매·주문, 직접·간접 전환, 목표 ROAS, 정산 데이터를 함께 봐야 한다.
- 플랫폼 내부 구매 환경은 고객 식별과 랜딩 통제가 제한될 수 있다. 이 경우 신규 고객 판정과 소재·랜딩 실험의 신뢰도가 낮아질 수 있다.
- 혼합 스토어프론트는 주문이 어디에서 확정되는지에 따라 데이터 권위가 달라진다.

## 웹·앱 구매 여정 의존

- 웹 구매 성과는 쿠키, UTM, 픽셀, 서버 이벤트, 주문번호 연결에 의존한다.
- 앱 구매 성과는 SDK, 딥링크, 앱 설치·실행 이벤트, 로그인 식별, 앱 내 구매 이벤트에 의존한다.
- 웹 클릭 후 앱 구매 또는 앱 클릭 후 웹 구매는 교차 환경 식별에 의존한다.
- 앱 푸시 성과는 수신동의, 푸시 토큰, 앱 설치 상태, 수신거부 상태에 의존한다.
- 플랫폼 내부 앱 구매는 플랫폼이 제공하는 리포트 권위에 더 많이 의존한다.

## 앱 측정 의존

- 앱 설치 어트리뷰션은 SDK 설치, MMP 설정, 광고 네트워크 연동, 앱스토어 또는 운영체제 포스트백, 딥링크 경로에 의존한다.
- 앱 구매 성과는 SDK 구매 이벤트, 서버 이벤트, 주문 DB, 앱스토어 인앱 결제 또는 외부 결제 정산 데이터에 의존한다.
- SKAN·AdAttributionKit 성과는 전환값 스키마, 포스트백 윈도우, 개인정보 보호 기준, 네트워크 연동 상태에 의존한다.
- MMP 이벤트 포스트백은 내부 이벤트명과 파트너 이벤트명 매핑에 의존한다.
- 딥링크 구매 성과는 광고 클릭, 앱 설치 여부, 앱 실행, 로그인 상태, 상품상세 도착, 결제 완료의 연속성에 의존한다.
- 앱 설치 캠페인의 ROAS 판단은 설치 수가 아니라 구매 이벤트와 정산 기준 결제액 연결에 의존한다.

## 채널 간 의존

- 검색광고는 브랜드 검색 수요와 자연 검색 노출에 의존한다. 브랜드 검색 성과는 신규 수요 창출로 단정하지 않는다.
- 쇼핑광고는 상품 피드, 가격, 배송, 리뷰, 재고, 플랫폼 랭킹에 의존한다.
- 소셜 광고는 소재, 오퍼, 랜딩, 픽셀·서버 이벤트 품질에 의존한다.
- 리테일 미디어는 플랫폼 내부 검색·추천·상품상세 노출과 직접·간접 전환 정의에 의존한다.
- CRM은 수신동의, 고객 상태, 구매 이력, 휴면 기준, 메시지 빈도에 의존한다.
- 제휴와 인플루언서는 쿠폰코드, 링크, 커미션, 광고 표시, 정산 기준에 의존한다.
- 자연 유입은 광고, 리뷰, 가격, 콘텐츠, 플랫폼 랭킹 변화의 영향을 받을 수 있으므로 독립 성과로 단정하지 않는다.

## 자연 발견 최적화 의존

- SEO는 크롤링 가능성, 색인 가능성, 페이지 구조, 상품 정보, 내부 링크, 검색 의도 적합성, 콘텐츠 품질에 의존한다.
- 플랫폼 SEO는 상품명, 카테고리, 속성, 이미지, 가격, 배송, 리뷰, 판매 가능 상태, 플랫폼 랭킹 신호에 의존한다.
- AEO는 질문형 콘텐츠 구조, 짧고 독립적인 답변, FAQ·HowTo·Product 등 구조화 데이터, 엔티티 명확성, 근거 가능 주장에 의존한다.
- GEO는 생성형 응답 표면의 검색·검색 증강 구조, 인용 가능한 문단, 엔티티 일관성, 외부 신뢰 신호, 리뷰·비교·추천 문맥, 출처 품질에 의존한다.
- AEO/GEO는 자사몰 콘텐츠만으로 결정되지 않는다. 플랫폼 상품 정보, 외부 리뷰, 커뮤니티 언급, 크리에이터 콘텐츠, 지식 패널, 소셜 검색 결과가 함께 영향을 줄 수 있다.
- 상품 가격, 재고, 환불 정책, 배송, 효능 주장이 표면마다 다르면 SEO/AEO/GEO 모두 신뢰와 선택 가능성이 약해진다.
- AI 응답의 인용·언급은 엔진 버전, 지역, 개인화, 프롬프트, 검색 결과 변화에 의존한다. 측정 스냅샷에는 시점과 조건을 보존해야 한다.

## 광고 노출 구조 의존

- 광고 채널 성과는 플랫폼뿐 아니라 노출 방식, 미디어 포맷, 노출 위치, 노출 시점에 의존한다.
- Search Ad 성과는 검색어 의도, 브랜드·논브랜드 구분, 검색 결과 위치, 키워드 매칭 방식에 의존한다.
- Display Ad 성과는 지면 맥락, 리타게팅 여부, 이미지·텍스트·영상 포맷, 빈도, 소재 피로에 의존한다.
- Shopping Listing Ad 성과는 상품 피드, 가격, 리뷰, 배송, 썸네일, 상품명, 플랫폼 랭킹에 의존한다.
- Retail Media Ad 성과는 플랫폼 내부 검색·추천·상품상세 위치, 직접·간접 전환 정의, 자연 판매와의 상호작용에 의존한다.
- Social Feed Ad 성과는 피드 맥락, 소재 첫 화면, 댓글·숨김·신고 반응, 공유·저장 행동에 의존한다.
- Video Ad 성과는 영상 길이, 초반 후킹, 음소거 시 이해 가능성, 랜딩 연결, 후속 검색 행동에 의존한다.
- Message Ad 성과는 수신동의, 발송 시간, 발송 빈도, 메시지함 위치, 수신거부 반영에 의존한다.
- Creator Native Ad 성과는 콘텐츠 신뢰, 대가 표시, 크리에이터 적합도, 쿠폰코드·링크 추적에 의존한다.
- 노출 시점이 구매 의도 후반부일수록 ROAS가 높아질 수 있다. 이 효과를 광고 소재나 플랫폼의 순수 우수성으로 단정하지 않는다.

## 상품 피드·카탈로그 의존

- 쇼핑광고와 카탈로그 광고는 상품명, 이미지, 가격, 재고, 카테고리, 브랜드, 상품 식별자, 랜딩 URL의 정합성에 의존한다.
- 상품 단위 ROAS는 상품 피드 ID, 이벤트 상품 ID, 주문 상품 ID가 서로 연결되는 구조에 의존한다.
- 리테일 미디어 성과는 플랫폼 상품 정보, 리뷰, 배송, 가격 경쟁력, 상품상세 품질, 광고 노출 위치에 의존한다.
- 동적 리타게팅은 조회·장바구니·구매 이벤트와 카탈로그 상품 ID 매칭에 의존한다.
- 피드 반려, 제한 노출, 가격·재고 불일치는 예산·입찰·소재 판단보다 먼저 해결해야 하는 선행 조건이다.

## Paid / Non-paid 의존

- Paid 성과는 매체비, 입찰, 타겟, 소재, 랜딩, 전환 추적에 직접 의존한다.
- Owned 성과는 고객 DB, 수신동의, 콘텐츠 자산, 발송 정책, 빈도 관리에 의존한다.
- Earned 성과는 리뷰 품질, 커뮤니티 반응, 상품 경험, 신뢰, 이슈 대응에 의존한다.
- Organic platform 성과는 플랫폼 알고리즘, 판매량, 리뷰, 가격, 배송, 품절률에 의존한다.
- Affiliate 성과는 파트너 품질, 커미션 구조, 쿠폰코드 중복, 정산 기준에 의존한다.
- Influencer 성과는 콘텐츠 신뢰, 팔로워 적합도, 대가 표시, 라이브·공동구매 운영에 의존한다.
- Mixed acquisition 성과는 중복 전환 제거와 접점 순서 기록에 의존한다.

## 데이터 권위 의존

- ROAS는 광고비, 광고 기여 결제액, 전환 기간, 어트리뷰션 모델에 의존한다.
- 내부 ROAS는 주문 결제액과 광고비 매칭에 의존한다.
- 기여이익은 주문 결제액, 원가, 수수료, 배송비 또는 제공 비용, 프로모션 비용, 광고비에 의존한다.
- CAC는 신규 고객 판정과 신규 획득 비용 범위에 의존한다.
- LTV는 반복구매율, 구매 간격, 마진 유지, 할인 의존도, 관측 기간에 의존한다.
- 반품 반영 ROAS는 구매 후 반품 데이터가 광고·주문과 연결되는 구조에 의존한다.
- 증분성 판단은 통제군 또는 비교 기준에 의존한다.

## 어트리뷰션 의존

- 클릭 기여는 클릭 ID 또는 UTM 보존에 의존한다.
- 조회 기여는 노출 로그와 플랫폼 모델에 의존하며 내부 검증이 제한될 수 있다.
- 마지막 클릭은 접점 순서 기록에 의존한다.
- 데이터 기반 기여는 플랫폼 관측 범위와 모델링에 의존한다.
- 주문번호 기준 중복 제거는 구매 이벤트와 주문 DB 연결에 의존한다.
- 플랫폼 간 중복 제거는 공통 주문번호, 고객 ID, 쿠폰코드, 시간 기준 매칭에 의존한다.
- 인플루언서·제휴 성과는 쿠폰코드, 링크, 파트너 ID, 구매 기간에 의존한다.

## 측정 신뢰도 의존

- 측정 신뢰도는 데이터 원천, 식별 키, 이벤트 시각, 중복 제거, 환불·반품 반영 여부에 의존한다.
- 서버 이벤트 신뢰도는 주문번호, 클릭 ID, 고객 식별자, 이벤트 전송 시점, 중복 제거 키에 의존한다.
- 오프라인 또는 외부 전환 업로드는 클릭 ID, 쿠폰코드, CRM 매칭 키, 업로드 결과 로그, 반려 내역에 의존한다.
- 정산 기준 성과는 주문 DB, 정산 DB, 수수료·환불·배송비 또는 제공 비용, 프로모션 차감 규칙에 의존한다.
- 증분성 판단은 테스트군·통제군 분리, 기간·지역·상품 조건 통제, 사전 중단 기준에 의존한다.
- 의사결정에 쓰는 지표의 권위는 가장 약한 선행 데이터의 신뢰도를 넘을 수 없다.

## CRM·수신동의 의존

- CRM 발송은 수신동의가 선행되어야 한다.
- 수신거부는 모든 발송 대상 선정보다 우선한다.
- 고객 세그먼트는 고객 식별자와 구매 이력에 의존한다.
- 휴면 고객 판정은 상품군별 구매 주기에 의존한다.
- 재활성화 성과는 발송 이력, 할인 비용, 구매 이력, 수신거부 변화에 의존한다.
- 광고성 정보 발송은 채널별 표시·거부 구조에 의존한다.

## 준수 의존

- 맞춤형 광고는 행태정보 처리 구조, 고지, 거부권, 플랫폼 정책에 의존한다.
- 광고성 정보는 수신동의, 광고 표시, 발신자 정보, 수신거부 수단에 의존한다.
- 할인·최저가 표현은 기준 가격, 기간, 재고, 실증 근거에 의존한다.
- 효능·성능·품질 표현은 객관적 근거와 업종별 제한에 의존한다.
- 후기·추천·보증 표현은 실제 경험, 대가 관계, 표시 방식에 의존한다.
- 전자상거래 랜딩은 판매자 정보, 배송, 환불, 청약철회, 추가 비용 고지에 의존한다.
- 플랫폼 광고 심사는 플랫폼별 금지 품목, 업종 제한, 소재 정책에 의존한다.
- 맞춤형 광고와 리타게팅은 행태정보 처리 고지, 거부권, 동의·거부 차단 목록, 플랫폼 데이터 사용 제한에 의존한다.
- 광고성 정보 발송은 채널별 수신동의 증빙, 수신거부 반영 로그, 발송 시각, 광고 표시 문구에 의존한다.
- 인플루언서·리뷰·공동구매 콘텐츠는 계약 또는 대가 관계, 노출물 내 광고 표시 캡처, 게시 이후 변경 이력에 의존한다.
- 전자상거래 프로모션은 캠페인 시작 시점의 거래조건 스냅샷에 의존한다.

## 순환 의존 감지

다음 순환은 별도 검토가 필요하다.

- 광고비 증액 → 판매량 증가 → 플랫폼 자연 노출 증가 → 전체 결제액 증가 → 광고 성과로 오인
- 쿠폰 강화 → 전환율 상승 → ROAS 상승 → 더 큰 쿠폰 집행 → 마진 악화
- 리타게팅 확대 → 단기 ROAS 상승 → 신규 획득 예산 축소 → 미래 신규 고객 감소
- CRM 발송 증가 → 단기 결제액 증가 → 수신거부 증가 → 장기 CRM 효율 하락
- 인플루언서 공동구매 → 브랜드 검색 증가 → 검색광고 전환 증가 → 인플루언서 효과 누락
- 품절 임박 → 광고비 유지 → 클릭 후 구매 실패 → 플랫폼 학습 악화

순환이 발견되면 원인과 결과를 단일 채널 성과로 확정하지 않고, 시간 순서와 비교 기준을 확인한다.

## 충돌 해결 우선순위

- 법률·플랫폼 준수 충돌은 준수가 우선한다.
- 정산 기준 결제액과 플랫폼 광고 기여 결제액 충돌은 정산 기준 결제액이 손익 판단에서 우선한다.
- 결제액과 회계상 매출이 충돌하면 먼저 목적을 구분한다. 성과 마케팅 판단은 결제액 권위를, 재무보고 판단은 회계상 매출 권위를 따른다.
- 재고 부족과 광고 증액 충돌은 재고 제약이 우선한다.
- 마진 손실과 결제액 확대 충돌은 사전 목표 모드가 우선한다. 목표 모드가 없으면 마진 손실 방지가 우선한다.
- 신규 획득과 기존 수요 회수 충돌은 고객 상태를 분리한 뒤 각각 판단한다.
- 단기 성과와 반복구매 가설 충돌은 검증된 코호트 근거가 있을 때만 반복구매 가설을 반영한다.

## 변경 영향 규칙

- 상품 가격 변경은 ROAS, CVR, AOV, 마진, 반품률 비교를 모두 무효화하거나 별도 기간으로 분리한다.
- 배송 정책 변경은 전환율, AOV, 기여이익, 반품률에 영향을 준다.
- 플랫폼 수수료 변경은 손익분기 ROAS를 재계산하게 한다.
- 태그·픽셀·SDK 변경은 전환 추적 연속성을 깨뜨릴 수 있으므로 변경 전후 리포트를 분리한다.
- 어트리뷰션 모델 변경은 과거 대비 성과 비교를 직접 불가능하게 만든다.
- 수신동의 정책 변경은 CRM 대상 규모와 결제액 비교를 바꾼다.
- 플랫폼 광고 정책 변경은 소재 승인, 타겟팅, 전환 추적, 데이터 사용 범위를 바꿀 수 있다.
