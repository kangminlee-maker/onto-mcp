실측 검증 결과 (2026-06-03) — 도구셋: subagent = Bash·Read·Write·Edit O, Agent·SendMessage X(∴ fan-out·peer 불가, 인라인 반환만). teammate = 위 + Agent·SendMessage O. 차단(실측): ❌ subagent→subagent, ❌ teammate→teammate, ❌ 재귀 TeamCreate. 가능(실측): ✅ teammate→subagent(PONG), ✅ teammate↔teammate 양방향 SendMessage(lead 경유 없이 직접, 7+5=12 회신). main 관측: idle 알림은 lead(메인)에 옴(실측), teammate끼리 DM 전문은 off-load되고 메인엔 요약 한 줄만 노출.

deliberation 매핑 — nested·flat = aggregator-mediated(onto 현행 controlled_lens_deliberation→synthesize와 정합) / flat+peer·flat+teamlead+peer = live peer(onto에 없던 신능력).

구현 우선순위 — ① onto subprocess flat·nested(codex 패턴에 claude 어댑터 추가, host 무관) → ② host Claude Code flat·nested(현행 deliberation 정합, main 최소) → ③ host peer 계열(live deliberation 신능력, 마지막).
