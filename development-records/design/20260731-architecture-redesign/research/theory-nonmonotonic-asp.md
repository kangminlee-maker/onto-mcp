# 이론 계열 적합성: 비단조 추론 · ASP · 논파가능 논리

- 작성: 2026-07-31, 아키텍처 재설계 탐색 워크플로의 subagent
- 계열: Answer Set Programming(안정모델 의미론), defeasible logic, circumscription, abduction/ILP
- 판정: **component_candidate** — 판정 커널로는 계열 중 최강, 단독 core로는 의미론 공백 때문에 실패

---

## 1. 이 계열이 이 시스템에서 하는 일 (미션 용어 번역)

학계 용어를 걷어내면 이 계열의 자산은 네 개의 기제다.

**(a) "규칙 + 기본 부정(default negation)" — 반례가 없으면 결론내리는 판정기.**
ASP의 규칙 `결론 :- 조건, not 반례.`는 "조건이 성립하고 반례가 *도출되지 않으면* 결론"이다. 이 미션 용어로는: 구현물에서 추출한 사실(span, import, config 키, 결정 기록)과 후보 이론(규칙)을 넣으면, 솔버가 **모든 정합적 세계관(answer set)** 을 결정론적으로 계산한다. 핵심은 결론이 프롬프트 서술이 아니라 **재실행 가능하고 반증 가능한 도출**이라는 것 — 같은 사실·같은 규칙이면 같은 판정, 반례 사실 하나가 추가되면 판정이 뒤집힌다.

**(b) 논파가능 규칙 + 우선순위 — "규칙은 있지만 예외가 있다"의 1급 표현.**
Defeasible logic(Nute 계열; Antoniou·Governatori 등)은 규칙을 3계급으로 나눈다: strict(반례 불허), defeasible(예외에 진다), defeater(결론을 막기만 하고 스스로 결론내지 않음), 그리고 규칙 간 우선순위(superiority). 미션 용어로: **구현물에서 귀납한 규칙은 태생적으로 defeasible이고, 예외는 규칙 삭제가 아니라 상위 우선순위 규칙 추가로 처리한다.** 기존 규칙을 지우지 않고 예외를 쌓는 이 구조는 진화(R4)의 되돌리기와 정확히 맞는다 — 규칙이 전부 텍스트 아티팩트이므로 git revert가 곧 믿음 개정의 역연산이다. 명제 논리 한정이면 추론이 선형 시간이라는 것도 알려져 있다.

**(c) Circumscription — "비정상 최소화"로서의 노이즈 판정.**
McCarthy의 한정은 "abnormal 술어의 외연을 최소화한 모델만 인정"이다. 미션 용어로: **구현물의 각 요소는 의도된 것으로 추정하되, 이론과 충돌하는 요소를 `abnormal`로 표시하고 그 총량을 최소화하는 해석을 고른다.** 최소 abnormal 집합 = "이 이론이 노이즈로 간주하는 것들의 목록"이고, 이것이 R1 판정의 반증 가능한 산출물이 된다. 다만 circumscription 자체는 도구가 없는 이론이고, 실무에서는 ASP의 `#minimize`/weak constraint로 동일한 것을 표현한다. inspiration으로만 계승한다.

**(d) 귀추(abduction)와 ILP — reconstruct의 논리적 정체.**
"관측(구현물의 사실)을 설명하는 최소 가설(개념·규칙)을 찾아라"는 귀추이고, "예제로부터 규칙 자체를 학습하라"는 ILP다. **reconstruct는 논리학 용어로 정확히 '노이즈 있는 관측으로부터의 이론 귀추/귀납'이다.** ASP에서 귀추는 choice rule + `#minimize`로 직접 표현되고(가설 후보를 열어두고 관측을 커버하는 최소 집합 탐색), ILP 쪽에는 노이즈 허용 예제(패널티 가중)로 answer set 프로그램을 학습하는 ILASP, 확장 지향의 FastLAS가 실재한다. 단, 뒤에 쓰듯 "사람 관여 0"은 여기서 깨진다.

부수 자산 하나: **brave/cautious 귀결 구분.** 다중 answer set이 있을 때 "모든 모델에서 참"(cautious)과 "어떤 모델에서 참"(brave)을 구분해 질의할 수 있다. 이것은 "결론이 하나로 안 나옴"을 뭉개지 않고 **확정 판정 / 가능 판정의 2단계 등급**으로 정직하게 표현하는 수단이다. clingo가 `--enum-mode=cautious/brave`로 직접 지원한다.

## 2. R1~R7 중 이 계열이 실제로 답하는 것

전부 답하지 않는다. 답하는 것은 R3·R4·R7(강), R1·R5(부분)이고, R2·R6의 어려운 절반에는 기여가 없다.

### R3 결론과 action의 결속 — **가장 강한 적합**

이 계열의 존재 이유가 여기다. 경계선이 corpus의 LLM/역량 경계 원칙과 정확히 포개진다:

- **LLM이 소유**: 규칙 저작(어떤 조건이 어떤 결론을 내는가의 의미 선택), 사실의 의미 해석이 필요한 술어의 채움(예: "이 span은 인증 로직이다"), 우선순위 부여의 근거.
- **결정론이 소유**: 사실 추출(tree-sitter 등 — 이미 있음), grounding, 안정모델 계산, brave/cautious 질의, 최적화, 도출 재생. **판정 자체는 솔버가 내리므로 "논리 체계가 결론을 낸다"가 문자 그대로 실행 가능해진다.**

결정적으로 이 구조에서 판정은 반증 가능하다: 규칙이 틀렸으면 반례 fixture 하나로 판정이 실패한다(음성 통제군 구성이 자명). "green이 실 경로를 통과했는가"의 검증 규율도 자연스럽다 — 판정의 입력(사실 집합)과 프로그램이 전부 직렬화 가능한 아티팩트이므로 replay가 정의적이다.

### R4 진화 시 무모순 유지 — **강한 적합**

- **충돌 탐지가 결정 가능하다.** 규칙 추가 후 재solve해서 (i) answer set이 사라지면(incoherent) 경성 충돌, (ii) 이전 판정 집합과 diff해서 뒤집힌 판정이 있으면 연성 충돌이다. "기존 판정과의 충돌 탐지"가 프롬프트 서술이 아니라 `이전 answer set들 vs 새 answer set들의 결정론적 diff`가 된다. 이는 현행 repo의 드리프트 리포트·ratchet 게이트와 같은 모양이며, 그것의 논리 계층 일반화다.
- **믿음 개정의 실무 형태**: AGM 이론을 직접 구현하는 게 아니라, defeasible 우선순위로 예외를 얹고(단조적 추가), 뒤집힌 판정 diff를 공시하고(비차단 — corpus의 하드블록 원칙과 일치), 수용/거부를 사람이 결정한다. 규칙이 git 관리 텍스트이므로 **되돌리기 = revert**로 완결된다.
- 한계: AGM식 "최소 변경 개정"의 자동 계산은 도구가 없고, 실무는 "재계산 + 회귀 diff"다. 이 미션에는 그걸로 충분하다고 판단한다 — 개정의 *수용 여부*는 어차피 의미 판단이라 LLM/사람 몫이다.

### R7 판정의 유용성 — **강한 적합**

- **왜**: 도출 트리가 곧 설명이다. 목표지향 ASP인 s(CASP)는 justification tree를 네이티브 산출하고, clingo 생태계에도 설명 도구(xclingo, clingexplaid(확인필요 — Potassco 산하 도구명))가 있다. 판정마다 "어느 사실 + 어느 규칙 + 어느 예외 부재"가 기계 산출된다.
- **무엇을 고쳐야**: 모델 기반 진단(Reiter)의 정확한 자리다. "정합성이 복원되는 최소 사실-변경 집합"을 ASP 최적화로 계산할 수 있다 — 위반 판정이 "틀렸다"에서 "이 3개를 바꾸면 통과한다"로 바뀐다. 이것은 review 산출물의 표현 요건("왜·무엇을")에 대한 이 계열의 구체적 답이다.
- 단서: 최소 수리 집합은 *구조적으로* 최소일 뿐 *의미적으로* 옳은 수정이 아닐 수 있다. 수리 후보의 의미 검토는 LLM 렌즈 몫으로 남는다.

### R1 노이즈로부터의 이론 귀납 — **부분 적합. 여기가 과대평가 위험 지점**

이 계열이 주는 것은 귀납 그 자체가 아니라 **귀납된 후보의 반증 가능한 채점기**다.

- 되는 것: LLM이 후보 규칙을 제안하면(의미 작업), 솔버가 추출 사실 전체에 대해 예외를 *센다*(결정론). "spans의 92%가 이 규칙을 만족, 예외 17건은 전부 test fixture 경로"처럼 **노이즈/개념 판정이 예외율·예외 분포라는 측정값으로 환원**되고, circumscription식 최소-abnormal 해석이 "이 이론이 노이즈로 취급하는 것"의 명시적 목록을 준다. 판정 근거가 도출이므로 반증은 반례 사실 하나로 충분하다 — R1의 "판정 근거와 반증 방법" 요구에 대한 정면 답이다.
- 안 되는 것: **"사람 관여 0" 귀납은 이 계열만으로 불가.** ILASP/FastLAS조차 가설 공간(language bias/mode declaration)을 누군가 저작해야 하고, 예제도 관계 사실로 이미 상징화되어 있어야 한다. 상징화(어떤 술어 어휘로 구현물을 사실화할 것인가)와 가설 공간 설계는 이 계열의 *입력*이지 산출이 아니다. 이 미션에서 그 자리를 채울 현실적 후보는 LLM이고, 그러면 R1은 "LLM 제안 → 논리 채점"의 루프가 된다 — 계열의 역할은 루프의 채점기 절반이다.

### R5 비용과 증분성 — **부분 적합**

- clingo의 multi-shot solving(프로그램 부분 추가/치환 후 재solve)이 실재하고, 사실 베이스를 소스 단위로 파티션하면 "변한 파티션만 재ground"가 가능하다. 캐시 무효화 단위 = 사실 파티션의 content_sha — 현행 CodeStructureInventory의 `content_sha256` + `extractor_logic_sha256` 회전 키와 **같은 개념이라 재사용하면 된다**(신규 개념 불필요).
- 정직한 한계: 실무적 증분은 "진짜 증분 추론"이 아니라 "영향 파티션 재계산"이다. 규칙이 파일 경계를 넘는 조인을 하면 재계산 범위가 번진다. 또한 grounding이 규칙의 변수 조인 폭에 지수적이라, 증분 이전에 grounding 규율(도메인 술어로 변수 범위 제한, 층화)이 선행 설계 대상이다.

### R2 자기적용 — **답하지 않음 (부분 기여만)**

기여: 이론 자체의 정합성 검사(answer set 존재 여부)는 결정 가능하고, ASP의 reification으로 규칙을 사실로 승격해 메타 규칙을 돌릴 수는 있다. 그러나 **무한퇴행·순환권위·자기승인을 막는 것은 논리가 아니라 권위 설계다** — 어떤 계층의 규칙이 어떤 계층을 판정할 수 있는가는 아키텍처(역량 표면)로 강제해야 하며, 이 계열은 그 답을 갖고 있지 않다. 부트스트랩 고정점도 마찬가지. 이 계열을 core로 뽑는 설계는 R2를 다른 곳에서 답해야 한다.

### R6 다형 소스 — **어려운 절반을 답하지 않음**

계열의 지평은 "관계 사실(atom)"로 단일하다 — 코드든 문서든 스프레드시트든 사실화되면 같은 솔버에 올라간다. 그러나 **사실화 어휘(술어 스키마) 설계가 R6의 실제 난제이고 이 계열은 거기에 백지**다. "하나의 지평"은 공짜로 얻는 게 아니라 소스 타입별 추출기 + 공용 술어 어휘를 설계한 *뒤에* 얻는 결과다. 오히려 위험: 술어 어휘를 소스 타입별로 방치하면 규칙이 타입별로 분열되어 개념 경제가 무너진다.

## 3. 깨지는 지점 (필수 명시)

1. **의미론 공백 — 단독 core 실격 사유.** "span X가 개념 Y를 실현한다"는 원자 사실은 도출되지 않고 *주어져야* 한다. 상징화가 틀리면 솔버는 틀린 사실 위에서 완벽하게 결정론적인 오답을 낸다. garbage-in에 대한 방어가 계열 내부에 없다. 이 계열은 상징화 이후의 세계만 담당한다 — 미션의 최난제(R1의 "무엇이 개념인가")의 절반은 이 계열의 상류에 있다.
2. **grounding 폭발.** 규칙이 span 쌍/삼중에 대해 조인하면 ground 인스턴스가 조합적으로 는다. 162k줄 규모의 사실화 자체는 문제없지만(수십만 atom은 clasp에 평범), 무규율한 규칙 저작 — 특히 LLM이 쓴 ASP — 이 grounding을 터뜨린다. disjunctive 프로그램은 Σ₂ᵖ까지 올라간다. 운영하려면 규칙 저작에 grounding 규율 게이트가 필요하다(이것 자체가 새 검증 표면).
3. **다중 answer set의 양날.** 소수의 모델은 "결론 불일치의 정직한 표현"이지만, 규칙이 느슨하면 모델이 조합적으로 폭발해 판정 산출물이 무의미해진다. `#show` 투영과 cautious/brave 규율, 그리고 "모델 수 상한 초과 = 이론이 덜 제약됨" 같은 메타 판정이 필요하다.
4. **디버깅 비직관성.** 비단조 프로그램의 오류(예상 못 한 모델 소거, even loop로 인한 incoherence)는 TS 스택트레이스 같은 친절함이 없다. 설명 도구가 있어도 저작자가 안정모델 의미론을 이해해야 한다. 1인 owner + LLM 저작 체제에서 이 학습 비용은 실질 리스크다 — LLM의 ASP 저작 품질은 주류 언어 대비 낮다(학습 데이터 희소).
5. **논파가능 논리 구현체의 생태계 빈약.** defeasible logic 전용 도구(SPINdle 등)는 유지보수가 정체됐다(확인필요 — 최근 활동 미확인). 실무 경로는 "defeasible 패턴을 ASP로 인코딩"이며, 이는 검증된 표준 인코딩이 있으나 계열 순수형 그대로의 도입은 비현실적이다.
6. **R2 무기여.** 위 §2 참조. core로 오인하면 자기적용 난제가 답 없이 남는다.

## 4. 현행 onto-mcp와의 접점 — 중복 도입 금지 지점

- **`.onto/domains/*/logic_rules.md`가 이미 이 계열의 자연어 전신이다.** "If A AND B → C. Resolution: ..." 형태의 조건 규칙 수백 건이 LLM 렌즈의 프롬프트 소재로 소비된다. 이 계열을 도입한다면 새 규칙 어휘를 만드는 게 아니라 **기존 logic_rules 중 기계화 가능한 부분집합의 실행 가능 투영**으로 설계해야 한다(개념 경제: 확장이지 신설이 아님). 역으로, 전부 기계화하려는 시도는 실패한다 — 상당수 규칙은 의미 판단("intent가 틀렸는지 axiom이 틀렸는지 구분하라")이라 LLM 몫이 맞다.
- **G1~G11 + INV 12종이 이미 'strict rule' 계급이다.** TS로 짠 결정론 게이트는 defeasible logic의 strict tier에 해당한다. 작동 중인 게이트를 ASP로 재작성하는 것은 순손실이고, 이 계열 도입 시 strict tier는 기존 TS 게이트로 두고 defeasible tier만 논리 계층이 맡는 분업이 맞다.
- **INV-BENCH-1의 PRELIMINARY 강등은 이미 논파가능 판정이다** — "벤치 결과는 유효하다, 단 반복·fixture·분산 요건 미달이라는 defeater가 발동하면 강등". 이 패턴이 비공식적으로 존재한다는 것은 계열의 적합 신호이자, 도입 시 정규화할 기존 개념이다.
- **CodeStructureInventory가 사실 추출 계층의 절반이다.** 다만 알려진 한계(상속/호출/타입 참조 엣지 부재, name resolution 부재)가 그대로 논리 계층의 표현력 상한이 된다 — 참조 엣지 없는 사실 위에서는 의존 규칙이 import 문자열 수준을 못 넘는다. 이 계열을 진지하게 쓰려면 사실 추출 확장이 선행 의존이다.
- **content_sha256/extractor_logic_sha256 재사용 키**가 R5의 캐시 무효화 단위로 그대로 재사용된다.

## 6. 판정

**component_candidate.** 이 계열은 미션의 "논리 체계가 결론을 낸다"를 문자 그대로 실행 가능하게 만드는 유일하게 성숙한 계열이다 — 판정의 결정론(R3), 충돌 탐지와 되돌리기(R4), 도출 기반 설명과 최소 수리(R7), 후보 이론의 반증 가능한 채점(R1의 절반)을 구체 도구(clingo)로 즉시 살 수 있다. brave/cautious와 다중 모델은 "결론 불일치"의 정직한 표현이라는 미션 요구에 정확히 맞는다. 그러나 상징화(무엇이 사실인가)와 의미 판정(무엇이 개념인가)에 백지이고 R2·R6의 난제를 답하지 않으므로, 단독 core로 뽑으면 시스템의 최난제가 계열 상류에 답 없이 남는다. 올바른 자리는 **LLM 상징화·규칙 제안 계층 아래의 결정론 판정 커널**이며, 이는 corpus의 LLM/역량 경계 원칙("LLM은 의미, 도구는 결정론 판정")과 구조적으로 동형이다. 도입 시 개념 경제 제약: logic_rules.md의 실행 가능 투영으로 설계하고, strict tier는 기존 TS 게이트에 남기고, 캐시 키는 기존 sha 개념을 재사용한다.
