## P1-C2 목표 (무엇을 입증)
P1-C1은 **LLM-0 결정론 substrate**만 깔았다. P1-C2 = 그 위에 **LLM 엔진(Layer 2)**을 얹어 "충실한 읽기"의 *의미* 부분을 처음으로 실측한다. 핵심 = **leaf 독해 + 의미 triage(깊이 배분) + 재귀 reduce(monoid)** + 그것을 resume-sound하게 만드는 **2-tier 에포크/`llm_touch_fingerprint` 실배선**. ComprehensionArtifact의 LLM-touch 필드(지금 `not_applicable`)를 *실제 값*으로 채우는 첫 producer.

## P1-C2 범위 (설계 SSOT 기준; P1-C1 §1·§9 이연 목록)
SSOT: `development-records/design/20260625-rescoped-comprehension-engine-design.md` §3.3(leaf)·§3.4(의미 triage)·§5(reduce 의미론)·§4(2-tier 에포크 resume).
1. **leaf-reader**(§3.2/§3.3): 위치 앵커(결정론·있음) + 라벨(고신뢰=결정론/저신뢰=LLM 잠정·is_lower_bound 태그) + value-signature tile(P1-C1 산물) → 홀로 해석 가능한 leaf. **국소화는 value-tile에 ground**(라벨 불확실해도 "어디서 바뀌는가"는 잡힘).
2. **의미 triage**(§3.4): 압축된 완전 증거(P1-C1 value-tile·인벤토리) 위에서 *어디에 의미 깊이를 줄지* LLM 배분. **policy digest만 게이팅 키(ⓑ)에 fold·allocation은 출력ⓒ(키 제외=non-circular)**. 깊이0 영역 정직 마킹(`semantic_depth_unvalidated`·라이프사이클 필드). ⚠️ Cut-2b가 allocation VIABLE 입증했으나 **안전경로 B(sniff 재진입·교차모델)는 미실증·이연**.
3. **재귀 reduce**(§5.1/§5.4/§5.5): same-schema monoid(canonical child-partition·grouping-invariance)·honesty fold(`is_lower_bound`=OR·`confidence`=min·국소화 맵)·synthesis COEXIST(기존 synthesis-map-reduce에 피드, REPLACE 아님).
4. **2-tier 에포크 / `llm_touch_fingerprint` 실배선**(§4.1/§4.4): Cut-4a는 **reference impl(미배선)**만 입증. P1-C2 = run.ts 실배선 + **non-circular-key validator**(게이팅 키에 에포크-내 출력ⓒ 누설 시 fail-closed) + model-identity-rotation·triage-policy-rotation 테스트. ComprehensionArtifact `provenance.epoch_fingerprint_contribution`을 실제 값으로.
5. **ComprehensionArtifact LLM-touch 필드 실현**: `spine_claims`·`semantic_depth`(+라이프사이클)·`confidence_by_claim`·`limiting_witness`·`consumer_handoff_notes` 등을 `producer_kind='llm'`로 채움. **T4 validator가 이미 강제**(llm producer는 not_applicable 금지) → P1-C2는 그 계약 상속.

- 후보 절단 = **leaf-reader(저신뢰 라벨 LLM 읽기 1개) + 2-tier 에포크 실배선** 부터 (triage·재귀 reduce는 그 다음 cut). "엔진 전체" 아니라 "LLM이 한 leaf를 resume-sound하게 읽는다"부터.
- ⚠️ **월 지출 한도** = 라이브 LLM sweep 당분간 불가([[effort-calibration-track]]) → P1-C2 빌드는 mock/fixture LLM 우선, 실 LLM 검증은 한도 회복 후.
