Codex caught two RECORD/PARK mis-calls in slice 9 that came from reading the obligation **id** instead of the **authoritative contract clause** (`ontology-seeding-and-maturation-design.md` §"…must enforce"):
- An id can be BROADER than the contract (e.g. `require_concept_economy_rationale_when_surface_increases` — the contract scopes it to `operation: add`+`increases_surface`, which the code enforces exactly; the refine case is OUT of contract, not a gap → RECORD, don't park).
- An id can be NARROWER than what the code skips (e.g. `prevent_in_place_seed_authority_rewrite` — the contract clause is unscoped "no in-place rewrite", but the basename-exact check misses anchored refs like `ontology-seed.yaml#…`; since target refs are LLM-authored free strings, that bypass is reachable → PARK).
So for each obligation: find the contract clause it derives from, compare the code to THAT, and judge RECORD/PARK against the contract scope.
