# Reconstruct SeedCandidate Legacy Archive

Status: archived historical reference.

validator and fixtures outside the product TypeScript source tree.

The active reconstruct runtime uses `ActionableOntologySeed`,
`candidate-disposition.yaml`, and `ontology-seed.yaml` validation gates.

or exposed through MCP/API conformance as current product behavior.
