# BLUEPRINT.md Retirement

`BLUEPRINT.md` was retired from the active documentation surface on 2026-05-21.

Reason: the blueprint format duplicated runtime, process, and roadmap truth across
too many sections, which made drift likely and maintenance expensive.

Active references now live in:

- `AGENTS.md` for agent-facing repository orientation
- `.onto/authority/core-lexicon.yaml` for canonical terms
- `.onto/processes/` for runtime process contracts
- `docs/architecture/` and `docs/decisions/` for architecture decisions
- `IMPLEMENTATION_MAP.html` for compact implementation and roadmap orientation
